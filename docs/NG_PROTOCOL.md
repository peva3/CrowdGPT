# NG protocol specification

Generated by `tools/gen_protocol_doc.py`. Do not edit by hand.

Schema version: `ng-1`. Wire tickets use `ng-ticket-1`. Legacy
round exports use `ng-legacy-1`; eval manifests use `ng-eval-1`.

## Wire rules

- Canonical JSON: UTF-8, sorted keys, compact separators `(',', ':')`,
  no NaN or Infinity. Digests are SHA-256 over canonical bytes.
- Losses are fixed six-place decimal **strings**, never floats.
- Ed25519 detached signatures cover the canonical bytes of the
  object's `signing_payload()`. Certificates are excluded from that
  payload and attached with `with_certificate`.
- Merkle roots are sorted-leaf SHA-256 roots with duplicate-last
  promotion. Inclusion proofs are verified against the root.
- Unknown fields are rejected. A schema change that adds a required
  field bumps the schema version; additive optional fields do not.

## Compatibility

Readers accept only the current schema version. Writers must emit
every required field. A record with an unknown version is rejected,
not silently downgraded. `RoundRecord.hash()` is content-addressed
and independent of the certificate.

## Versioning

- `ng-1`: round records, node records, receipts, checkpoints, evals.
- `ng-ticket-1`: signed admission tickets.
- `ng-legacy-1`: imported pre-NG round snapshots.
- `ng-eval-1`: held-out eval manifest.

A change to canonical encoding, signature scope, or a required field
is breaking: bump the version and keep a reader for the old one until
every published record has aged out.
